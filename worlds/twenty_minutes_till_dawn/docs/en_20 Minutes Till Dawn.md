# 20 Minutes Till Dawn

## Randomizer Summary

The 20 Minutes Till Dawn randomizer turns every run into a piece of a larger progression system. Characters, Weapons, and Maps all need to be unlocked, and each Character / Weapon's access to a longer session is gated behind Progressive Timer items. Darkness starts at a high point and must be worn down with Progressive Darkness Reduction items, while Runes are collected purely as helpful bonuses along the way. Depending on your goal, you'll either gather a set number of Forbidden Tomes spread across the multiworld, or collect enough of them to allow you to win by surviving 20 minutes on a designated level.

**Locations**
- Per Map:
  - Kill Count Checkpoints
  - Per Character / Weapon:
    - Survival Time Checkpoints
    - Player Level Checkpoints

**Items**
- Forbidden Tomes
- Progressive Darkness Reductions
- Per Map:
  - Map Unlock
  - Progressive Timers (+4 Minutes per)
- Per Character:
  - Character Unlock
  - Progressive Powerup Choices
  - Heart Containers
  - Soul Heart Capacity
- Per Weapon:
  - Weapon Unlock
- Per Rune:
  - Rune Points

## Randomizer Features
- Ability to select individual Characters / Weapons to include / exclude from generation
- Ability to customize how many Characters (1-13) and Weapons (2-11) to play with
- Ability to set / randomize the starting Map
- Ability to customize starting Darkness (0-15) and the Darkness level considered fully survivable in logic
- Optional Weapon Attribute Randomization with a configurable per-attribute chance
- 4 unique traps to experience with configurable weights
- Death Link support (with the ability to toggle it off with a command)
- Scales well for all types of multiworlds: Short / Long Syncs, Asyncs; ~160-1100 checks
- Custom client UI that displays important information and updates in real-time
- No manual mod installation required! The Archipelago client hooks into the game at runtime. Nothing else to download, install, or configure.
- Feature-complete and tested

## Tracking

**Universal Tracker**

The APWorld is fully compatible with Universal Tracker. It is a YAML-free implementation (i.e. you don't need to have the YAML used to generate in your Players directory). If Universal Tracker is installed, the client will automatically embed the Tracker tab and will also enhance some of its views with in / out of logic data.
