# Severed Steel

## Randomizer Summary

The Severed Steel Randomizer takes the levels and mechanics of Firefight 2.0 and turns them into progression for a multiworld. Clearing levels is only part of it; you'll also need to chase ranks, target times, headshots, and various challenges to unlock what's needed to progress. Along the way, you can unlock new levels, reduce fresh cooldowns, reduce your multiplier burn rate, and pick up various per-level upgrades.

**Locations**
- Per Level:
  - Killing 10 / All Enemies 
  - Killing 7 Enemies with Headshots
  - Obtaining B / A / S / S+ / S++ Ranks
  - Beating a Target Time
  - Completing the 2 Vanilla Challenges
  - Completing X Custom Stylish Action Challenges

**Items**
- Progressive Multiplier Burn Rate Reductions
- Progressive Fresh Cooldown Reductions
- Level Unlocks
- Stylish Actions Licenses (for Custom Stylish Action Challenges)
- Per Level:
  - 10% Target Time Discount
  - Double Score
  - Unlimited Ammo Unlocked
  - Unlimited Cannon Ammo Unlocked
  - Invincibility Unlocked

## Randomizer Features
- All 51 Firefight 2.0 levels are supported
- 2 goals to choose from:
  - `EdenSys Root Keys + Final Level`: Collect enough EdenSys Root Keys to unlock a Final Level and clear it
  - `EdenSys Root Key Hunt`: Collect a set number of EdenSys Root Keys spread across the multiworld
- Ability to select individual levels to include / exclude from generation
- Ability to customize how many levels (12-51) to play
- Ability to specify a percentage of levels that will be required to play with a mutator active from various mutator pools
- Ability to specify a percentage of levels that will be required to play in mirrored mode
- Ability to generate up to 5 custom stylish action challenges per level that become locations (e.g. 3x Wall Bang, 7X Dive Frag)
- Ability to set / randomize the difficulty of target rank scores / times. By level or globally
- Option to play in Invincible Mode (to allow for more focus on style and comboing)
- 8 unique traps to experience with configurable weights and durations
- Scales well for all types of multiworlds: Short / Long Syncs, Asyncs; ~90-750 checks
- Custom client UI that displays important information and updates in real-time
- No manual mod installation required! The Archipelago client hooks into the game at runtime. Nothing else to download, install, or configure.
- Feature-complete and considered stable


## Tracking

**Universal Tracker**

The APWorld is fully compatible with Universal Tracker. It is a YAML-free implementation (i.e. you don't need to have the YAML used to generate in your Players directory). If Universal Tracker is installed, the client will automatically embed the Tracker tab.
