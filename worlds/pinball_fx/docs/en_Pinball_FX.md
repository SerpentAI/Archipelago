# Pinball FX

## Randomizer Summary

The Pinball FX Randomizer turns Pinball FX into a progression-based experience where a table's game modes must be unlocked as you play. Progress comes from reaching target scores across a variety of tables and challenge modes, while scoring-related upgrades help you manage tougher targets along the way.

**Locations**
- Per Table:
  - Classic Mode Target Scores: Low / Mid / High / Very High
  - 1 Ball Challenge Target Scores: Low / Mid / High / Very High
  - Flips Challenge Target Scores: Low / Mid / High / Very High
  - Time Challenge Target Scores: Low / Mid / High / Very High
  - Distance Challenge Target Scores: Low / Mid / High / Very High

**Items**
- Per Table:
  - Classic Mode Unlock
  - 1 Ball Challenge Unlock
  - Flips Challenge Unlock
  - Time Challenge Unlock
  - Distance Challenge Unlock
  - Useful Score-Related Items

## Randomizer Features
- All 140 pinball tables across current DLC are supported
  - Updates adding support any future tables to be expected
- 2 goals to choose from:
  - `Shiny Quarters + Final Level`: Collect enough Shiny Quarters to unlock a Final Level and meet a High target score to win
  - `Shiny Quarter Hunt`: Collect a set number of Shiny Quarters spread across the multiworld to win
- Ability to select individual tables to include / exclude from generation
- Ability to customize how many tables (6-140) to play
- Target scores are accurately scaled per table and game mode
- Ability to set / randomize difficulty of target scores. By table or globally.
- Ability to convert filler items into useful items during generation to help tackling the difficulty
- 6 unique traps to experience with configurable weights and durations
- Scales well for all types of multiworlds: Short / Long Syncs, Asyncs; 30-2780 checks
- Custom client UI that displays important information and updates in real-time
- No manual mod installation required! The Archipelago client hooks into the game at runtime. Nothing else to download, install, or configure.
- Feature-complete and considered stable

## Tracking

**Universal Tracker**

The APWorld is fully compatible with Universal Tracker. It is a YAML-free implementation (i.e. you don't need to have the YAML used to generate in your Players directory). If Universal Tracker is installed, the client will automatically embed the Tracker tab.
